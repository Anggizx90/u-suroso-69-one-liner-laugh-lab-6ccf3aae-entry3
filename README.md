Write one short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock. The funniest, most original line wins.

Our entry — the vacuum's excuse, in its own deadpan voice:

> My job description is one word: floor. The sock was on the floor. I rest my case.

81 characters, one line. The joke is absurd literalism: the vacuum treats "floor" as both its job description and its jurisdiction, then closes with a courtroom punchline — not the stock "it looked tasty" excuse.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader), after checking the gate's own caps: 1–200 characters, one line, not only whitespace.
